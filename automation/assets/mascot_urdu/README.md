# Farq Kya Mascot Asset Library (`assets/mascot_urdu/`)

This directory holds the tag-coded PNG image assets for the **Farq Kya** (@farqkya) YouTube channel mascot.

## Mascot Visual Specs:
- Minimal stickman wearing a white taqiyah cap with light-blue trim and a navy blue thobe.
- Art style: Super-minimal, thick-black-outline matching the original mascot.
