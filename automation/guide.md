# 📖 YouTube Shorts Automation - Minimal Guide

This guide explains how to generate scripts live in your terminal, review/validate them, pick specific ones to build CapCut drafts for, and view tracker status.

---

All historical YouTube Shorts and fresh unuploaded scripts are tracked in a clean CSV file openable in **Excel**, **Google Sheets**, **VSCode**, or **Notepad**:

## ⚡ 2. Live CLI Script Generation & Selective Draft Building

Run this command in your terminal:

```bash
python run_batch.py
```

### What Happens Step-by-Step:
1. **Live Generation**: The `ScriptGenerator` automatically generates **10 fresh scripts (5 Deep Dives + 5 Compilations)** right in front of you in the terminal.
2. **Interactive CLI Review**: All 10 scripts are displayed with their **Format** (`DEEPDIVE` / `COMPILATION`), **X vs Y entities**, **Topic**, and **Script text**.
3. **Select Drafts by Number**: You type the numbers of the scripts you want to create CapCut drafts for (e.g. `1, 3, 5` or `2` or `ALL`):

```text
======================================================================
📋 BATCH REVIEW & SELECTION (10 Topics Generated)
======================================================================
[01] FORMAT: DEEPDIVE    | X vs Y: Uru Metal vs Vibranium
     TOPIC : Uru vs Vibranium: Which Metal Is Stronger?
     SCRIPT: "This is Uru Metal. This is Vibranium. So what's the difference?..."

[02] FORMAT: DEEPDIVE    | X vs Y: Wolverine vs Deadpool
     TOPIC : Wolverine vs Deadpool: Healing Factor Diff
     SCRIPT: "This is Wolverine. This is Deadpool. So what's the difference?..."
...
======================================================================
Options:
  [A / ALL] Approve All & Start Batch Execution
  [1, 3, 5] Select Specific Numbers to Build Drafts For
  [G] Generate 10 Fresh 50/50 Scripts (5 Deepdives + 5 Compilations)
  [Q] Quit
======================================================================
👉 Select scripts to generate drafts for (e.g. '1, 3, 5' or 'ALL' / 'A'): 1, 3, 5
```

- If you type `1, 3, 5`, ONLY topics #1, #3, and #5 will be sent to the video pipeline to generate CapCut drafts!
- If you type `ALL` (or press Enter), ALL 10 topics will build CapCut drafts!
